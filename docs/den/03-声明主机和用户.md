# 声明主机和用户

Den 框架的核心实体是**主机（host）** 和**用户（user）**，以及可选的独立**家庭（home）**配置。本文详细介绍如何在 Den 中声明这些实体。

## 主机声明

主机通过 `den.hosts` 声明，语法为 `den.hosts.<system>.<name>`，其中 `system` 是 Nix 平台字符串（如 `x86_64-linux`），`name` 是主机标识名。

```nix
{
  # 基本的主机声明
  den.hosts.x86_64-linux.igloo = { };

  # 多平台声明
  den.hosts.aarch64-darwin.apple = { };
}
```

每个主机实体暴露以下选项：

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | `str` | 属性名 | 主机配置名称 |
| `hostName` | `str` | `name` | 网络主机名（`networking.hostName`） |
| `system` | `str` | 属性名中的 system | 平台字符串 |
| `class` | `str` | 推导值 | 配置类：`nixos` 或 `darwin` |
| `aspect` | `raw` | `den.aspects.<name>` | 用于配置该主机的方面 |
| `users` | `attrsOf` | `{ }` | 该主机上的用户 |
| `instantiate` | `raw` | 按 class 推导 | 实例化函数 |
| `intoAttr` | `listOf str` | 按 class 推导 | flake 输出路径 |
| `description` | `str` | 自动生成 | 主机描述 |

### class 字段

`class` 决定主机的配置类型：

```nix
{
  # NixOS 主机（默认）
  den.hosts.x86_64-linux.server = {
    class = "nixos";
  };

  # nix-darwin 主机
  den.hosts.aarch64-darwin.macbook = {
    class = "darwin";
  };
}
```

class 的默认推导逻辑：如果 system 以 `darwin` 结尾则为 `darwin`，否则为 `nixos`。

### hostName 示例

```nix
{
  den.hosts.x86_64-linux.my-laptop = {
    hostName = "xps15";  # 覆盖默认名称
  };

  # 生成的 networking.hostName 将使用 hostName
}
```

### instantiate 和 intoAttr

Den 使用 `instantiate` 函数将主机配置转化为最终的 NixOS/nix-darwin 配置，`intoAttr` 决定结果在 flake 输出中的存放路径：

```nix
{
  den.hosts.x86_64-linux.server = {
    # 使用自定义 nixpkgs 实例化
    instantiate = inputs.nixos-unstable.lib.nixosSystem;

    # 自定义输出路径
    intoAttr = [ "nixosConfigurations" "my-server" ];
  };
}
```

## 用户声明

用户通过 `den.hosts.<system>.<name>.users.<name>` 声明：

```nix
{
  den.hosts.x86_64-linux.igloo = {
    users = {
      tux = { };
      alice = { };
    };
  };
}
```

每个用户实体暴露以下选项：

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | `str` | 属性名 | 用户配置名称 |
| `userName` | `str` | `name` | 系统用户名 |
| `classes` | `listOf str` | `[ "homeManager" ]` | 使用的家庭环境类 |
| `aspect` | `raw` | `den.aspects.<name>` | 用于配置该用户的方面 |
| `host` | `host` | 所属主机 | 父主机引用 |

### 用户 classes 字段

`classes` 控制该用户使用哪些家庭环境：

```nix
{
  den.hosts.x86_64-linux.igloo.users.tux = {
    # 默认：只使用 home-manager
    classes = [ "homeManager" ];
  };

  den.hosts.x86_64-linux.igloo.users.pingu = {
    # 同时使用 home-manager 和 hjem
    classes = [ "homeManager" "hjem" ];
  };

  den.hosts.x86_64-linux.igloo.users.bob = {
    # 只使用 OS 级用户（无家庭环境）
    classes = [ "user" ];
  };
}
```

## 独立家庭管理器声明

除了主机管理的用户家庭配置外，还可以通过 `den.homes` 声明独立的家庭管理器配置：

```nix
{
  # 绑定到主机的独立家庭配置
  den.homes.x86_64-linux."tux@igloo" = { };

  # 无绑定主机的独立家庭配置
  den.homes.x86_64-linux."alice" = { };
}
```

命名约定 `"user@host"`：`@` 之前是用户名，之后是主机名。省略 `@host` 则为无绑定配置。

每个独立家庭实体暴露以下选项：

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | `str` | 用户名 | 家庭配置名称 |
| `userName` | `str` | 用户名 | 系统用户名 |
| `hostName` | `nullOr str` | 从命名推导 | 绑定主机名 |
| `class` | `str` | `"homeManager"` | 家庭管理类 |
| `aspect` | `raw` | `den.aspects.<name>` | 配置方面 |
| `system` | `str` | 属性名中的 system | 平台字符串 |
| `pkgs` | `raw` | 推导值 | nixpkgs 实例 |
| `instantiate` | `raw` | 推导值 | 实例化函数 |
| `intoAttr` | `listOf str` | 推导值 | flake 输出路径 |
| `description` | `str` | 自动生成 | 配置描述 |
| `host` | `nullOr host` | 推导值 | 绑定的主机实体 |
| `user` | `nullOr user` | 推导值 | 绑定的用户实体 |

## 实体之间的关系

Den 的实体之间存在清晰的层次关系：

```
den.hosts  →  主机 (host)
                 ├── 用户 (user) 1  →  家庭环境 (homeManager/hjem/maid)
                 ├── 用户 (user) 2  →  家庭环境
                 └── ...

den.homes  →  独立家庭 (home)
                 ├── 可能绑定到 host
                 └── 可能绑定到 user
```

- **主机拥有用户**：`host.users` 列出该主机的所有用户
- **用户绑定到主机**：`user.host` 引用所属主机
- **家庭绑定主机和用户**：`home.host` 和 `home.user` 在命名包含 `@host` 时自动推导

### Host→User 穿透

主机方面中嵌套的用户名键会自动穿透到用户作用域：

```nix
{
  den.hosts.x86_64-linux.igloo.users.tux = { };

  # 主机方面中的 tux 键自动传递给用户
  den.aspects.igloo = {
    nixos = { ... };           # 主机配置
    tux.nixos = { ... };       # 自动穿透到用户 tux 的主机级配置
  };
}
```

## 多架构声明

Den 支持在不同架构上声明主机：

```nix
{
  # x86_64 Linux 主机
  den.hosts.x86_64-linux.desktop = {
    hostName = "ryzen";
    class = "nixos";
    users.alice = { };
  };

  # aarch64 Linux 主机（如树莓派）
  den.hosts.aarch64-linux.raspi = {
    hostName = "pi4";
    class = "nixos";
    users.alice = { };
  };

  # aarch64 Darwin 主机（Mac）
  den.hosts.aarch64-darwin.macbook = {
    hostName = "mbp";
    class = "darwin";
    users.alice = { };
  };

  # x86_64 Darwin 主机（旧款 Mac）
  den.hosts.x86_64-darwin.macmini = {
    class = "darwin";
  };
}
```

注意：Darwin 主机需要添加 `inputs.darwin` 输入。

## 使用 Freeform 属性扩展实体

Den 的实体支持 freeform 属性，这意味着除了标准选项外，可以添加任意自定义属性：

```nix
{
  den.hosts.x86_64-linux.server = {
    # 标准选项
    hostName = "myserver";

    # Freeform 扩展
    tags = [ "production" "web" ];
    location = "us-east-1";
    monitoring.enable = true;

    users.deploy = {
      userName = "deploy-bot";
      sshKeys = [ "ssh-ed25519 AAAA..." ];
      roles = [ "admin" "deploy" ];
    };
  };
}
```

这些自定义属性可以在方面函数中通过 `host` 上下文参数访问：

```nix
{
  den.aspects.monitoring = { host, ... }: {
    nixos = {
      services.prometheus.enable = host.monitoring.enable or false;
    };
  };
}
```

## 完整示例

以下是一个典型的多主机、多用户声明：

```nix
{
  # ====== 主机声明 ======

  # 个人笔记本
  den.hosts.x86_64-linux.laptop = {
    hostName = "thinkpad";
    description = "我的个人笔记本";
    tags = [ "personal" "mobile" ];

    users.tux = { };
    users.alice = { };
  };

  # 家庭服务器
  den.hosts.x86_64-linux.server = {
    hostName = "nas";
    class = "nixos";
    location = "basement";

    users.deploy = {
      userName = "cicd";
      classes = [ "user" ];
    };
    users.media = {
      userName = "media-server";
      classes = [ ];
    };
  };

  # MacBook
  den.hosts.aarch64-darwin.macbook = {
    hostName = "macbook-pro";
    class = "darwin";

    users.tux = {
      classes = [ "homeManager" ];
    };
  };

  # ====== 独立家庭配置 ======

  # 绑定到 laptop 的 tux 用户的独立 HM
  den.homes.x86_64-linux."tux@laptop" = { };

  # 无绑定主机的独立 HM
  den.homes.x86_64-linux."remote-user" = { };
}
```

## 最佳实践

### 命名约定

- **主机名**：使用简短、有意义的名称，如 `igloo`、`laptop`、`server`
- **用户名**：使用系统登录名，与 `userName` 保持一致
- **家庭标识**：使用 `user@host` 格式明确绑定关系

### 组织方式

推荐将主机和用户声明放在单独的文件中：

```
modules/
  hosts/
    hosts.nix           # 所有主机/用户/家庭的声明
    igloo/
      igloo.nix         # 主机 igloo 的方面配置
      tux.nix           # 用户 tux 的方面配置
    server/
      server.nix
      deploy.nix
```

### 要点

- 在 `den.hosts` 中声明所有主机，不要遗漏
- 每个用户关联一个 `den.aspects.<name>` 方面
- 独立家庭通过 `den.homes` 声明，仅在需要脱离主机管理时使用
- Freeform 属性是从外部向方面传递元数据的好方法
- `class` 字段决定实例化方式，确保与 system 匹配
