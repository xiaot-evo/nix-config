# 内置电池（Batteries）

Den 框架提供了一系列开箱即用的**电池（batteries）**，以 `den.batteries` 命名空间下的即用型方面形式存在。电池封装了常见的配置模式，让用户可以快速搭建系统而无需从头编写样板配置。

## 使用方式

电池通过 `includes` 引入：

```nix
{
  den.aspects.my-host = {
    includes = [
      den.batteries.hostname
    ];
  };

  # 全局启用
  den.default.includes = [
    den.batteries.hostname
    den.batteries.unfree
  ];
}
```

## 系统类电池

系统类电池主要作用于 NixOS/nix-darwin 主机级配置。

### den.batteries.hostname — 设置主机名

从 `den.hosts.<system>.<name>.hostName` 自动设置系统的网络主机名：

```nix
{
  den.hosts.x86_64-linux.myserver = {
    hostName = "myserver";
  };

  # 全局启用后自动设置所有主机的 hostName
  den.default.includes = [ den.batteries.hostname ];
}
```

NixOS 上设置 `networking.hostName`，Darwin 上设置相应的 hostName 选项。

### den.batteries.define-user — 创建系统用户

在 OS 层和家庭管理器层同时创建用户。这是最常用的电池之一：

```nix
{
  den.hosts.x86_64-linux.igloo.users.tux = { };

  den.aspects.tux = {
    includes = [ den.batteries.define-user ];
    # 之后就可以直接在 homeManager 中配置
    homeManager.home.packages = [ pkgs.neovim ];
  };
}
```

该电池自动：
- 在 NixOS 上创建 `users.users.<userName>`，设置 `isNormalUser = true`
- 在 Darwin 上创建相应的用户条目
- 设置 `home.username` 和 `home.homeDirectory`（Linux: `/home/<name>`，macOS: `/Users/<name>`）

### den.batteries.primary-user — 主用户

在 `define-user` 基础上，将用户提升为主用户：

```nix
{
  den.aspects.tux = {
    includes = [
      den.batteries.define-user
      den.batteries.primary-user
    ];
  };
}
```

该电池自动：
- NixOS：添加 `wheel` 和 `networkmanager` 组
- Darwin：设置 `system.primaryUser`
- WSL：设置 `wsl.defaultUser`

### den.batteries.user-shell — 设置用户 Shell

设置用户的默认 Shell，同时在 OS 和家庭管理器层启用该 Shell：

```nix
{
  den.aspects.tux = {
    includes = [
      den.batteries.define-user
      (den.batteries.user-shell "fish")
    ];
  };
}
```

这会启用 `programs.fish.enable = true` 并设置用户的 shell 为 fish。

### os 类 — OS 便利类（nixos + darwin 双转发）

提供 `os` 类，同时在 `nixos` 和 `darwin` 中生效。由 `os-class` 模块自动注册，默认启用，无需手动添加到 `includes`：

```nix
{
  den.aspects.my-host = {
    # os 类的配置自动转发到 nixos 和 darwin（取决于主机 class）
    os.networking.hostName = "foo";
  };
}
```

使用内置策略 `den.policies.os-to-host` 实现，将 `os` 类内容路由到主机的目标类。该模块通过 `den.default.includes` 自动启用。

### user 类 — 用户便利类（users.users.<name> 转发）

提供 `user` 类，是无需 home-manager 依赖的轻量级用户环境。由 `os-user` 模块自动注册，自动将方面中的 `user` 类内容转发到 OS 的 `users.users.<userName>`：

```nix
{
  den.aspects.alice = {
    # 不使用 user 类时
    # nixos.users.users.alice.packages = [ pkgs.hello ];
    
    # 使用 user 类后
    user.packages = [ pkgs.hello ];
    user.extraGroups = [ "wheel" ];
  };
}
```

使用内置策略 `den.policies.user-to-host` 实现路由。该模块通过 `den.default.includes` 自动启用。

### WSL 支持

启用 WSL 支持。由 `wsl` 模块自动注册，不可作为 `den.batteries.*` 手动引入。需要 flake input 中包含 `nixos-wsl`：

```nix
{
  # 在单个主机上启用
  den.hosts.x86_64-linux.igloo.wsl.enable = true;

  # 或在所有 NixOS 主机上启用
  den.schema.host.wsl.enable = true;
}
```

启用后可用的主机选项：
- `host.wsl.enable` — 是否启用 WSL
- `host.wsl.module` — 自定义 WSL 模块（默认：`inputs.nixos-wsl.nixosModules.default`）

WSL 模块还提供了 `wsl` 类，可在方面中使用：

```nix
{
  den.aspects.igloo = {
    wsl.wsl.base = true;
  };
}
```

### den.batteries.forward — 创建转发类

将一个类的配置转发到另一个类的选项路径下，用于创建自定义配置类：

```nix
{
  # 创建 custom 类，内容转发到 nixos.services.my-service
  den.aspects.my-service = den.batteries.forward {
    each = lib.singleton true;
    fromClass = _: "custom";
    intoClass = _: "nixos";
    intoPath = _: [ "services" "my-service" ];
    fromAspect = _: myAspect;
  };

  den.aspects.app.custom = { enable = true; port = 8080; };
}
```

转发还支持 `guard` 条件守卫和 `adaptArgs` 参数适配：

```nix
{
  # 带条件守卫的转发
  den.batteries.forward {
    each = lib.singleton class;
    fromClass = _: "imper";
    intoClass = _: "nixos";
    intoPath = _: [ "impermanence" ];
    fromAspect = _: lib.head aspectChain;
    guard = { options, ... }: options ? impermanence;
  };
}
```

### den.batteries.import-tree — 按 _class 目录递归导入

对于现有的大型配置，按目录结构自动导入 Nix 文件：

```nix
{
  # 导入 ./disko/ 目录下的 _nixos 子目录
  den.aspects.my-disko.includes = [ (den.batteries.import-tree ./disko/) ];
}
```

目录结构约定：

```
disko/
  _nixos/              # 自动导入到 nixos 类
    disko-config.nix
  _homeManager/        # 自动导入到 homeManager 类
    me.nix
```

可以为不同实体提供上下文感知的导入：

```nix
{
  # 主机感知：自动导入 ./hosts/<hostname>/_nixos
  den.schema.host.includes = [ (den.batteries.import-tree.provides.host ./hosts) ];

  # 用户感知：自动导入 ./users/<username>/{_homeManager, _nixos}
  den.schema.user.includes = [ (den.batteries.import-tree.provides.user ./users) ];
}
```

> **注意**：`den.batteries.mutual-provider` 现在是一个空的兼容层。跨实体路由（`provides.to-users`、`provides.to-hosts`）已内置于管道中，无需额外电池。旧配置包含它可以继续工作，但新代码不需要导入它。

### den.batteries.host-aspects — 将主机方面投射到用户

将主机方面中定义的 `homeManager` 类内容自动转发到该主机的用户：

```nix
{
  den.aspects.igloo = {
    nixos = { ... };
    # 主机为所有用户提供默认家庭配置
    provides.to-users.homeManager = { pkgs, ... }: {
      home.packages = [ pkgs.vim ];
    };
  };

  den.aspects.tux = {
    includes = [ den.batteries.host-aspects ];
    # 自动接收 igloo 提供的 homeManager 基础配置
  };
}
```

## 家庭环境电池

### Home Manager 集成

启用 Home Manager 支持。由 `home-manager` 模块自动注册，不可作为 `den.batteries.*` 手动引入。只需声明用户即可使用：

```nix
{
  # 声明使用 home-manager 的用户
  den.schema.user.classes = [ "homeManager" ];

  # 主机上启用 HM 的用户自动获得 HM 配置
  den.hosts.x86_64-linux.igloo.users.tux = { };
}
```

该模块自动注册 `homeManager` 类，创建 Host→User 的 HM 转发通道。

### Hjem 集成

启用 [hjem](https://github.com/feel-co/hjem)（Rust 实现的 Home Manager 替代品）支持。由 `hjem` 模块自动注册，不可作为 `den.batteries.*` 手动引入：

```nix
{
  # 需要 flake inputs 中包含 hjem
  # inputs.hjem.url = "github:feel-co/hjem";

  den.schema.user.classes = [ "homeManager" "hjem" ];
}
```

添加后可以同时在方面中使用 `hjem` 类：

```nix
{
  den.aspects.tux = {
    includes = [ den.batteries.host-aspects ];
    hjem = { pkgs, ... }: {
      packages = [ pkgs.neovim ];
    };
  };
}
```

### Nix-Maid 集成

启用 [nix-maid](https://github.com/maid) 声明式家政服务。由 `maid` 模块自动注册，不可作为 `den.batteries.*` 手动引入：

```nix
{
  # 需要 inputs.nix-maid
  den.schema.user.classes = [ "homeManager" "maid" ];
}
```

```nix
{
  den.aspects.tux = {
    maid."${config.home.homeDirectory}/Downloads" = {
      rules = [
        { type = "extension"; extensions = [ "pdf" ]; dest = "Documents"; }
      ];
    };
  };
}
```

## 包管理电池

### den.batteries.unfree — 允许不自由包

按包名列表允许使用不自由（unfree）包：

```nix
{
  # 全局应用
  den.default.includes = [ (den.batteries.unfree [ "vscode" "slack" "steam" ]) ];

  # 或按主机应用
  den.aspects.gaming.includes = [ (den.batteries.unfree [ "steam" "discord" ]) ];
}
```

该电池自动适应上下文：在 `nixos` 类中设置 `nixpkgs.config.allowUnfreePredicate`，在 `homeManager` 类中也设置相应选项。

### den.batteries.insecure — 允许不安全包

按包名允许使用已知不安全的包：

```nix
{
  den.default.includes = [
    (den.batteries.insecure [ "openssl-1.1.1" "python-2.7.18" ])
  ];
}
```

## Flake-Parts 电池

### den.batteries.flake-scope — 暴露 lib/inputs/den 到管道函数

向方面管道函数注入 `lib`、`inputs` 和 `den` 值。这是 `self'` 和 `inputs'` 的基础设施：

```nix
{
  den.default.includes = [ den.batteries.flake-scope ];
}
```

启用后，方面函数的上下文参数将包含 `lib`、`inputs` 和 `den`。该电池使用 `pipelineOnly`（`collisionPolicy = "class-wins"`），确保类模块原生值优先。

### den.batteries.self' — 提供 self' 模块参数

将 flake-parts 提供的 `self'`（预选择系统的 flake self）注入模块参数：

```nix
{
  # 全局推荐
  den.default.includes = [ den.batteries.self' ];
}
```

启用后，模块中可以直接使用 `self'` 访问当前系统的 flake 输出：

```nix
{
  den.aspects.my-host = { self', ... }: {
    nixos.environment.systemPackages = [ self'.packages.default ];
  };
}
```

### den.batteries.inputs' — 提供 inputs' 模块参数

类似 `self'`，但提供预选择系统的 `inputs'`：

```nix
{
  den.default.includes = [ den.batteries.inputs' ];
}
```

```nix
{
  den.aspects.my-host = { inputs', ... }: {
    nixos.environment.systemPackages = [ inputs'.nixpkgs.legacyPackages.hello ];
  };
}
```

## 便利电池

### den.batteries.vm-autologin — VM 自动登录

在虚拟机中启用自动登录，适合开发测试：

```nix
{
  den.aspects.my-vm.includes = [ (den.batteries.vm-autologin "tux") ];
}
```

这会在 `virtualisation.vmVariant` 中设置自动登录，仅影响 `nixos-rebuild build-vm` 构建的虚拟机。

### den.batteries.tty-autologin — TTY 自动登录

在物理 TTY1 上启用自动登录：

```nix
{
  den.aspects.laptop.includes = [ (den.batteries.tty-autologin "alice") ];
}
```

与 VM 版不同，此电池影响实际系统 TTY。

## 电池组合使用的完整示例

以下示例展示了如何在一个实际配置中组合多个电池：

### 个人工作站

```nix
{ pkgs, lib, den, ... }: {
  # ====== 全局电池 ======
  den.default = {
    includes = [
      den.batteries.hostname
      (den.batteries.unfree [ "vscode" "slack" "steam" ])
      den.batteries.self'
      den.batteries.inputs'
    ];

    # 全局状态版本
    nixos.system.stateVersion = "25.05";
    homeManager.home.stateVersion = "25.05";
  };

  # ====== 主机声明 ======
  den.hosts.x86_64-linux.workstation = {
    hostName = "xps15";
    users.alice = { };
  };

  # ====== 主机方面 ======
  den.aspects.workstation = {
    includes = [
      den.batteries.hostname
    ];

    nixos = { pkgs, ... }: {
      boot.loader.systemd-boot.enable = true;
      services.openssh.enable = true;
    };

    # 为主机用户提供默认家庭配置
    provides.to-users.homeManager = { pkgs, ... }: {
      home.packages = [ pkgs.vim ];
    };
  };

  # ====== 用户方面 ======
  den.aspects.alice = {
    includes = [
      den.batteries.define-user
      den.batteries.primary-user
      (den.batteries.user-shell "fish")
      den.batteries.host-aspects
      (den.batteries.vm-autologin "alice")
    ];

    homeManager = { pkgs, ... }: {
      home.packages = with pkgs; [ neovim htop ripgrep ];
    };
  };
}
```

### 多家庭环境服务器

```nix
{ lib, den, ... }: {
  # HM 和 hjem 由各自模块自动注册，无需手动 include

  den.hosts.x86_64-linux.server = {
    hostName = "nas";
    users.bob = {
      classes = [ "homeManager" "hjem" ];
    };
    users.ci = {
      classes = [ "user" ];  # 只创建 OS 用户
    };
  };

  den.aspects.bob = {
    includes = [
      den.batteries.define-user
      (den.batteries.user-shell "bash")
    ];

    homeManager = { pkgs, ... }: {
      home.packages = [ pkgs.htop ];
    };

    hjem = { pkgs, ... }: {
      packages = [ pkgs.neovim ];
    };
  };

  den.aspects.ci = {
    includes = [ den.batteries.define-user ];
    # classes = [ "user" ] — 不创建 HM，只有系统用户
  };
}
```

## 电池清单

| 电池 | 作用域 | 说明 |
|------|--------|------|
| `hostname` | 主机 | 自动设置网络主机名 |
| `mutual-provider` | 通用 | **已弃用**——跨实体路由已内建 |
| `define-user` | 用户 | 创建完整的 OS + HM 用户 |
| `primary-user` | 用户 | 设为超级用户（wheel/管理员） |
| `user-shell <shell>` | 用户 | 设置用户默认 Shell |
| `forward` | 通用 | 创建自定义类转发 |
| `import-tree [path]` | 通用 | 按 `_class` 目录递归导入 |
| `host-aspects` | 用户 | 接收主机的用户级配置 |
| `unfree [pkgs]` | 通用 | 允许不自由包 |
| `insecure [pkgs]` | 通用 | 允许不安全包 |
| `flake-scope` | 通用 | 向管道暴露 `lib`/`inputs`/`den` |
| `self'` | 通用 | 提供 `self'` 参数 |
| `inputs'` | 通用 | 提供 `inputs'` 参数 |
| `vm-autologin <user>` | 主机 | VM 自动登录 |
| `tty-autologin <user>` | 主机 | TTY 自动登录 |
