# C4 模型渲染器

**源文件**: `nix/lib/diag/c4.nix`

## 概述

C4 模型渲染器提供两种后端的三种视图框架。C4 模型从四个层次（上下文、容器、组件、代码）审视软件架构。Den 的 C4 渲染器将方面图映射到此模型：

- **组件图（Component）**：每个方面是一个组件，按实体类型分组为容器
- **容器图（Container）**：每个实体类型是一个容器，显示方面数量
- **上下文图（Context）**：舰队级视图，主机=系统，用户=人员

两种渲染后端：
1. **PlantUML**：使用 `!include <C4/C4_*>` 标准库
2. **Mermaid**：使用原生 C4 图类型

两者共享相同的宏体语法（`Person(...)`、`System(...)`、`Rel(...)`），仅框架头不同。

---

## toC4Component / toC4ComponentWith — 组件图

**签名**: `({ theme? }) → (graph: graphIR) → string`

### 用途

每个主机级别，将方面显示为组件，按实体类型分组到容器中。

### 结构

```
@startuml
!include <C4/C4_Component>
title Component view: <hostName>

System_Boundary(<hostId>, "<hostName>") {
  Container_Boundary(<kind>, "<kind>") {
    Component(<aspectId>, "<aspectName>", "<class>")
  }
}

Rel(<from>, <to>, "includes")
@enduml
```

### 使用示例

```nix
# PlantUML
c4String = diag.toC4Component graph;
c4String = diag.toC4ComponentWith { inherit theme; } graph;

# Mermaid
c4String = diag.toC4ComponentMermaid graph;
c4String = diag.toC4ComponentMermaidWith { inherit theme; mermaidConfig = {}; } graph;
```

---

## toC4Container / toC4ContainerWith — 容器图

**签名**: `({ theme? }) → (graph: graphIR) → string`

### 用途

每个实体类型显示为一个容器盒子，显示其包含的方面数量。实体类型转换边（entity edges）成为 `Rel`。

### 结构

```
@startuml
!include <C4/C4_Container>
title Container view: <hostName>

System_Boundary(<hostId>, "<hostName>") {
  Container(<kindId>, "<kind>", "<classHint>", "<aspectCount> aspects")
}

Rel(<from>, <to>, "resolve")
@enduml
```

---

## toC4Context / toC4ContextWith — 上下文图

**签名**: `({ theme? }) → (fleet: fleetRecord) → string`

### 用途

舰队级概览。显示整个 Den flake 中所有主机和用户之间的关系。

### 输入

接收 `fleet.nix` 构建的舰队记录 `{ flakeName, hosts, users, relations }`：

```nix
fleet = diag.fleet.of {};
c4String = diag.toC4Context fleet;
```

### 结构

```
@startuml
!include <C4/C4_Context>
title <flakeName> — Fleet Context

Person(<userId>, "<userName>")
System(<hostId>, "<hostName>", "<description>")
Rel(<from>, <to>, "<className>")
@enduml
```

## Mermaid 后端

C4 Mermaid 渲染器使用 Mermaid 的 `C4Component`、`C4Container`、`C4Context` 图类型：

```nix
# Mermaid C4 组件图
c4String = diag.toC4ComponentMermaidWith {
  inherit theme;
  mermaidConfig = {
    layout = "elk";
  };
} graph;
```

Mermaid 的 C4 图尊重 `themeVariables` 配置，不支持 `skinparam` 指令。

## 完整渲染器列表

| 函数 | 后端 | 视图 | 说明 |
|------|------|------|------|
| `toC4Component` | PlantUML | 组件 | 方面级 |
| `toC4Container` | PlantUML | 容器 | 实体类型级 |
| `toC4Context` | PlantUML | 上下文 | 舰队级 |
| `toC4ComponentMermaid` | Mermaid | 组件 | 方面级 |
| `toC4ContainerMermaid` | Mermaid | 容器 | 实体类型级 |
| `toC4ContextMermaid` | Mermaid | 上下文 | 舰队级 |
| `toC4*With` 变体 | 两者 | 同上 | 带配置的版本 |
