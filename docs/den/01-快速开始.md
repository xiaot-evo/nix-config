# 快速开始

本指南将带你从零开始创建第一个 Den 配置。我们假设你已经安装了 Nix 并熟悉基础的 `configuration.nix`。

## 环境要求

- **Nix 2.18+**（推荐使用最新稳定版）
- **Flakes 可选**——Den 同时支持 Flakes 和非 Flakes 环境。本教程将展示两种方式
- 基本的 Nix 语言知识

## 最小配置：从零开始

我们将逐步创建一个 NixOS 主机 `igloo` 和一个用户 `tux` 的完整配置。

### 方式 A：使用 Flakes（推荐）

#### 步骤 1：创建项目目录结构

```console
mkdir -p ~/nixos-config/modules
cd ~/nixos-config
```

#### 步骤 2：创建 flake.nix

```nix
# flake.nix
{
  description = "我的 Den NixOS 配置";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    den.url = "github:denful/den";
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };

  outputs = { self, nixpkgs, den, home-manager, ... }: {
    nixosConfigurations = (den.lib.evalModules {
      modules = [
        den.module

        # 声明主机
        {
          den.hosts.x86_64-linux.igloo.users.tux = {};

          den.aspects.igloo = {
            includes = [ den.batteries.hostname ];
            nixos = { pkgs, ... }: {
              environment.systemPackages = [ pkgs.hello ];
            };
          };

          den.aspects.tux = {
            includes = [
              den.batteries.define-user
              den.batteries.primary-user
            ];
            homeManager = { pkgs, ... }: {
              home.packages = [ pkgs.vim ];
              home.stateVersion = "25.05";
            };
          };

          den.default.homeManager.home.stateVersion = "25.05";
        }

        # Home Manager 集成
        ({ config, ... }: {
          den.schema.user.classes = [ "homeManager" ];
        })
      ];
    }).config.flake.nixosConfigurations;
  };
}
```

这个文件做了什么：

| 部分 | 作用 |
|------|------|
| `inputs.den` | 引入 Den 框架 |
| `inputs.home-manager` | 引入 Home Manager（可选） |
| `den.lib.evalModules` | 使用 Den 的模块求值器 |
| `den.module` | 导入 Den 框架模块 |
| `den.hosts.x86_64-linux.igloo` | 声明一个名为 igloo 的 x86_64 NixOS 主机 |
| `den.aspects.igloo` | 增强主机 igloo 的方面——添加 hostname 电池和 hello 包 |
| `den.aspects.tux` | 增强用户 tux 的方面——创建系统用户并赋予管理员权限 |
| `den.schema.user.classes` | 为用户启用 Home Manager |

#### 步骤 3：构建

```console
# 构建但不切换
nix build .#nixosConfigurations.igloo.config.system.build.toplevel

# 或者直接部署（需要 root）
sudo nixos-rebuild switch --flake .#igloo
```

### 方式 B：不使用 Flakes（使用 npins）

如果你不想使用 Flakes，Den 同样支持得很好。

#### 步骤 1：初始化 npins

```console
mkdir -p ~/nixos-config/modules
cd ~/nixos-config
npins init
npins add github denful den
npins add github nix-community home-manager
```

#### 步骤 2：创建 default.nix

```nix
# default.nix
let
  sources = import ./npins;
  den = import sources.den {};
in
(den.lib.evalModules {
  modules = [
    den.module
    ({ ... }: {
      imports = [ (import sources.home-manager).nixosModules.home-manager ];

      den.hosts.x86_64-linux.igloo.users.tux = {};

      den.aspects.igloo = {
        includes = [ den.batteries.hostname ];
        nixos = { pkgs, ... }: {
          environment.systemPackages = [ pkgs.hello ];
        };
      };

      den.aspects.tux = {
        includes = [
          den.batteries.define-user
          den.batteries.primary-user
        ];
        homeManager = { pkgs, ... }: {
          home.packages = [ pkgs.vim ];
          home.stateVersion = "25.05";
        };
      };

      den.default.homeManager.home.stateVersion = "25.05";
      den.schema.user.classes = [ "homeManager" ];
    })
  ];
}).config.flake.nixosConfigurations
```

#### 步骤 3：构建

```console
nixos-rebuild build --file . -A igloo
```

### 推荐配置：使用 Flake Parts

对于更大的项目，推荐将 Den 与 flake-parts 结合使用：

```nix
# flake.nix
{
  description = "我的 Den + flake-parts 配置";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    flake-parts.url = "github:hercules-ci/flake-parts";
    den.url = "github:denful/den";
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };

  outputs = inputs@{ flake-parts, den, ... }:
    flake-parts.lib.mkFlake { inherit inputs; } {
      systems = [ "x86_64-linux" "aarch64-linux" ];

      imports = [ den.flakeModule ];

      perSystem = { config, pkgs, ... }: {};

      den = {
        hosts.x86_64-linux.igloo.users = {
          tux = {};
          alice = {};
        };

        aspects.igloo = {
          includes = [
            den.batteries.hostname
            { nixos.environment.systemPackages = [ pkgs.hello ]; }
          ];
        };

        aspects.tux = {
          includes = [
            den.batteries.define-user
            den.batteries.primary-user
          ];
          homeManager = { pkgs, ... }: {
            home.packages = [ pkgs.vim ];
            home.stateVersion = "25.05";
          };
        };

        aspects.alice = {
          includes = [ den.batteries.define-user ];
          homeManager = { pkgs, ... }: {
            home.packages = [ pkgs.emacs ];
            home.stateVersion = "25.05";
          };
        };

        schema.user.classes = [ "homeManager" ];
        default.homeManager.home.stateVersion = "25.05";
      };
    };
}
```

## 逐步解释

### 步骤 1：在 flake.nix 中添加 Den 输入

```nix
inputs = {
  den.url = "github:denful/den";
};
```

这引入了 Den 框架及其所有功能。

### 步骤 2：声明第一个主机

```nix
den.hosts.x86_64-linux.igloo.users.tux = {};
```

这行代码做了几件事：
- 声明了一个名为 `igloo` 的主机，架构为 `x86_64-linux`（自动推断 class = "nixos"）
- 在该主机上声明了一个用户 `tux`
- Den **自动创建**了 `den.aspects.igloo` 和 `den.aspects.tux` 两个空方面

用户也可以有额外属性：

```nix
den.hosts.x86_64-linux.igloo.users = {
  tux = {
    classes = [ "homeManager" ];  # 启用 Home Manager
    shell = "zsh";                # 自由格式属性，可在方面中读取
  };
};
```

### 步骤 3：增强主机方面

```nix
den.aspects.igloo = {
  includes = [ den.batteries.hostname ];
  nixos = { pkgs, ... }: {
    environment.systemPackages = [ pkgs.hello ];
  };
};
```

- `includes` 引入内置电池——`den.batteries.hostname` 会自动设置 `networking.hostName`
- `nixos` 属性就是普通的 NixOS 模块，可以导入任何 NixOS 配置

### 步骤 4：增强用户方面

```nix
den.aspects.tux = {
  includes = [
    den.batteries.define-user
    den.batteries.primary-user
  ];
  homeManager = { pkgs, ... }: {
    home.packages = [ pkgs.vim ];
  };
};
```

- `den.batteries.define-user` 在系统层面创建用户账户
- `den.batteries.primary-user` 将该用户添加为管理员（wheel 组）
- `homeManager` 属性就是普通的 Home Manager 配置

### 步骤 5：使用内置电池

电池（Batteries）是 Den 预置的可复用方面。上面的例子中已经用了几个：

| 电池 | 作用 |
|------|------|
| `den.batteries.hostname` | 自动从主机声明设置 `networking.hostName` |
| `den.batteries.define-user` | 创建系统用户账户（`users.users.<name>`） |
| `den.batteries.primary-user` | 赋予管理员权限（wheel 组） |
| `den.batteries.user-shell` | 设置用户登录 shell |

更多电池见[电池参考文档](https://den.denful.dev/reference/batteries/)。

### 步骤 6：构建和部署

```console
# 构建
nix build .#nixosConfigurations.igloo.config.system.build.toplevel

# 部署到当前系统（需要 root）
sudo nixos-rebuild switch --flake .#igloo

# VM 测试（无需重启）
nix build .#nixosConfigurations.igloo.config.system.build.vm
```
