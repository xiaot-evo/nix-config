# AGENTS.md 分层设计规格

## 背景

AGENTS.md 是项目根目录下的 AI 代理参考文档。原文件混合了通用框架信息和具体项目配置细节，导致内容冗余、维护成本高。

## 目标

将 AGENTS.md 拆分为两层：

1. **AGENTS.md** — 通用参考，描述项目架构模式、Den 框架概念、工作流流程、构建命令等不经常变化的内容
2. **AGENTS_PROJECT.md** — 项目专属，包含主机详情、用户配置、功能模块状态、已知 TODOs 等具体信息

## AGENTS.md（通用）内容设计

### 1. 构建 & 部署
- `nix run .#<host>` 构建 / `nix run .#<host> -- switch` 部署
- `nix run .#vm` 虚拟机
- `nix run .#write-flake` 重新生成 flake.nix
- `nix flake update den` 更新框架输入
- 提及 `nh` 底层使用，`den.lib.nh.denPackages`

### 2. CI
- `nix flake check` 作为 CI gate
- ubuntu + macos 双平台运行
- `_module.args.CI = true` 条件

### 3. 项目结构
- 高层级目录树（只显示 `hosts/`, `features/`, `packages/` 级别，不含具体文件）
- flake.nix 自动生成说明（编辑 dendritic.nix → `nix run .#write-flake`）
- import-tree 递归导入机制

### 4. Den 框架参考
- Aspects 概念：静态 / 参数化 / 转发 / 条件式 四种类型
- Entities：主机和用户拓扑定义
- Batteries：内置便捷 aspects 说明
- Classes：nixos / homeManager，默认值，strict mode
- `includes` / `provides` 组合与跨类连接模式（使用抽象示例，不含真实配置）
- Aspect 命名规范：路径 → dot-separated

### 5. Flake Inputs
- 所有输入表（保留，通用信息）

### 6. 创建新功能模块的流程
- 纯流程步骤，无状态表格

### 7. Packages 包装器模式
- `inputs.wrappers` 说明
- 使用方式 `nix run .#<name>`

### 8. Superpowers 工作流
- 所有可用技能表
- 标准新功能工作流：brainstorming → writing-plans → TDD → flake check → review → finish
- 调试工作流：debugging → TDD → verify → flake check

### 9. Vibe Coding 标准
- 8 条标准化操作指南
